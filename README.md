## 🧪 How I Document Experiments

I want every project to be reproducible and honest about what didn't work. Each repo aims to include:

| | |
|---|---|
| ❓ **Question** | What exactly is being tested, and why |
| ⚙️ **Setup** | Model, data, seeds, hardware, and one-command reproduction |
| 📊 **Results** | Tables and plots, not just a final number |
| 🔍 **Ablations** | What changes when a component is removed or altered |
| ⚠️ **Limitations** | Where the result may not hold |
| ➡️ **Next steps** | What I'd try next |
